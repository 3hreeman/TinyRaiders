# 카메라 · 전장의 안개 · 미니맵

## 조작

- 새 게임은 자유 카메라로 시작하며 플레이어의 초기 위치를 보여줍니다.
- 화면 가장자리 또는 전투 화면 가장자리로 마우스를 옮기면 그 방향으로 이동합니다. 버튼 등 UI 위에서는 가장자리 이동을 막습니다.
- 전투 화면 위에서 휠을 위로 돌리면 확대, 아래로 돌리면 축소합니다. 줌과 이동 모두 카메라의 보이는 사각형 전체가 맵 내부에 있도록 제한합니다.
- Space를 누르면 플레이어 중심으로 즉시 이동하고 이후 플레이어를 추적합니다. 맵 가장자리에서는 경계 제한이 우선합니다.
- 가장자리 이동 또는 미니맵 클릭은 추적을 해제하고 자유 카메라로 전환합니다.
- 미니맵의 원하는 위치를 클릭하면 카메라만 이동합니다. 캐릭터에게 이동 명령을 보내지 않습니다.
- Escape는 기존 일시정지/재개를 유지합니다. Space는 더 이상 일시정지 키가 아닙니다. 증강 선택·타이틀에서는 카메라 조작을 막습니다.

## 편집 위치

메인 카메라의 `ArenaCameraController`에서 기본/최소/최대 Orthographic Size, 가장자리 감지 폭, 이동 속도, 휠 줌 속도를 조정합니다. 기본 크기는 3.375, 범위는 1.6875–5.875이며 맵보다 넓어지는 값은 자동 제한합니다. 카메라는 1280 × 720 기준 상단 (40,45)부터 1200 × 675 영역을 표시하여 하단 HUD 뒤까지 이어집니다. HUD는 화면 위에 겹쳐 표시하며 UI 위의 클릭은 월드로 전달하지 않습니다. 해상도가 바뀌어도 같은 비율을 유지합니다.

`World`의 `FogOfWarPresenter`에서 시야 반경(기본 논리 좌표 560)과 안개 격자 해상도(192)를 조절합니다. 시야는 카메라 위치와 무관하게 플레이어를 중심으로 갱신합니다. 현재 시야는 밝게, 탐색한 영역은 어둡게, 미탐색 영역은 불투명하게 표시합니다. 새 게임은 탐색 기록을 초기화합니다. 이는 원형 시야이며 나무·바위 뒤의 시선 차폐는 계산하지 않습니다.

시야 밖 적은 월드와 미니맵에서 숨기고 마우스로 직접 선택할 수 없게 합니다. 투사체·장판·FX도 시야에 맞춰 표시를 제한합니다. 전투 시뮬레이션은 계속 진행하며, 보이지 않는 영역에 대한 광역 스킬 등의 피해 규칙은 그대로입니다.

`UI/…/Hud/ArenaMinimap`은 저장된 Canvas 오브젝트입니다. `Inset/MapWell` 아래 Terrain, WorldMarkers, Fog, OverlayMarkers 레이어로 나뉩니다. 탐색한 장애물, 현재 보이는 적, 플레이어, 카메라 시야 사각형을 표시합니다. UI 위치와 크기는 RectTransform으로 수정할 수 있습니다.

## 맵 및 재연결

평원·사막·동굴은 논리 3600 × 3600, 기본 카메라 시야는 약 1440 × 2068입니다. HUD 뒤까지 세로 시야를 넓히면서 기존 월드와 캐릭터의 화면상 크기는 유지합니다. 기존 바닥의 픽셀 밀도를 유지하기 위해 9개 타일을 사용하고 가장자리 타일을 잘라 맵 범위에 맞췄습니다. 기존 중앙 장식은 유지하고 외곽 구역을 추가했습니다. `Layout3600-v1`은 확장 이중 적용을 막는 표식입니다.

환경 메뉴를 적용하면 `WorldExplorationBuilder.Configure`가 카메라·안개·미니맵 참조를 함께 갱신합니다. `MinimapAuthoring.Apply`는 이미 편집한 UI 오브젝트를 재사용합니다. 위치 판정은 `WorldProjection.ScreenToWorld`에서 실제 카메라 광선을 지면과 교차시켜 줌·이동 뒤에도 일치합니다.
