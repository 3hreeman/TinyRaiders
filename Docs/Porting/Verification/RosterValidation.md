# 전체 직업 및 8방향 확장 검증

2026-09-20 · Unity 6000.5.4f1 · 원본 `D:/Codex/Arcade`의 Survival League.

## 구현

- 검사·궁수·마법사 선택, 직업별 기본 공격과 Q/W/E/R, 선택한 직업으로 재도전.
- 원본 직업 3개, 플레이어 스킬 12개, 특별 증강 22개. 기존 D/F와 일반 증강 및 엘리트 보상 흐름 유지.
- 세 플레이어 캐릭터 각각 8방향 × 6프레임(대기 1, 이동 2, 공격 3): 총 144개 프레임을 PNG 아틀라스로 저장.
- 원본 몸/무기 배율과 투영을 구분해 적용. 방향에 따른 전후면과 무기 깊이 순서를 유지하고 모든 프레임의 경계 잘림을 점검.
- 에셋 구성과 재생성: `../CharacterAtlases.md`, 미리보기: `../CharacterAtlasOverview.png`.

## 자동 검증

Unity EditMode **46개 통과, 실패 0개**. 기존 궁수 테스트 21개와 새 직업 테스트 25개를 실행했습니다.

검증에는 직업별 초기 수치/스킬, 검사 강화 공격 소모와 범위 피해, 보호막 흡수/반사/만료, 회전 공격 20틱 및 이동 추적, 대검 낙하 지연과 중심 피해, 마법사 연쇄 대상과 피해 감소, 화염구 폭발/관통, 빙결, 순간이동 거리/명령 정지, 과부하 피해 및 쿨타임 회복, 주요 직업 증강의 실제 효과, 직업별 특별 보상 필터링이 포함됩니다.

기획 에이전트가 원본 TypeScript의 스킬/증강 해석 로직과 데이터 구성을 대조했으며, 이 범위에서 추가 수정이 필요한 불일치는 발견하지 않았습니다.

## Unity 화면 검증

최종 Presentation 통합 후 Unity 컴파일 오류가 없음을 확인했습니다. 세 아틀라스 모두 Resources에서 768×1024, Point 필터로 로드됩니다. 실제 Play Mode에서 선택 UI 및 검증용 전투 상황을 구성하고 Game View를 1920×1080으로 캡처해 확인했습니다.

- `roster-selection.png`: 세 직업 선택 카드, 직업별 QWER 안내와 D/F 선택.
- `roster-swordsman.png`: 검사 HUD, 반사 보호막, 회전 공격 및 피해 표시.
- `roster-mage.png`: 마법사 HUD, 빙결 범위, 투사체 및 과부하 효과.

전투 캡처는 효과를 검수하기 위해 에디터에서 적 위치와 스킬 사용을 지정한 상황입니다. 새 두 직업으로 키보드/마우스만 사용해 전체 런을 완주한 수동 검증은 하지 않았습니다. 전투/성장 규칙은 자동 테스트로 확인했으며 Play Mode 검수 중 런타임 Exception은 없었습니다. 검증 후 Play Mode를 종료하고 SurvivalLegend 씬을 열어두었습니다.

## 빌드

사용자 요청에 따라 **새 Windows/WebGL 빌드는 생성하지 않았습니다**. 기존 `Builds/`와 로컬 웹 서버는 이전 궁수 버전입니다. 최신 구현은 `Assets/SurvivalLegend/Scenes/SurvivalLegend.unity`에서 Play로 확인합니다.
