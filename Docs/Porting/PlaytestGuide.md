# Survival Legend — Unity 플레이 안내

원본 웹 게임의 SD 그래픽 방향과 전투 규칙을 옮긴 Unity 버전입니다. 첫 궁수 버전의 플레이 확인 후 검사·마법사와 세 직업의 8방향 리소스를 추가했습니다.

## 실행

- Unity: `Assets/SurvivalLegend/Scenes/SurvivalLegend.unity`를 열고 Play를 누릅니다. Game View는 1280×720 등의 가로 화면을 사용하세요.
- 이번 확장은 사용자 요청에 따라 별도 빌드를 만들지 않습니다. **아래 PC/Web 결과물은 이전 궁수 버전**입니다. 새 캐릭터와 8방향 리소스는 Unity 에디터에서 확인하세요.
- PC: `Builds/Windows/SurvivalLegend.exe`를 실행합니다. 실행 파일과 같은 폴더의 데이터 파일도 필요합니다.
- 웹: 프로젝트 폴더에서 `node Tools/serve-web.mjs`를 실행하고 `http://127.0.0.1:8765`에 접속합니다. `index.html`을 파일로 직접 여는 방식은 지원하지 않습니다.
- 다시 빌드: Unity 메뉴 **Survival Legend → Build Windows / Build WebGL**.

## 조작

| 입력 | 동작 |
| --- | --- |
| 바닥 우클릭 / 유지 | 이동 / 0.25초마다 목적지 갱신 |
| 적 우클릭 | 추적 후 기본 공격 반복 |
| A 후 좌클릭 | 공격 이동 또는 적 지정 공격 |
| S | 정지 |
| Q | 집중 사격: 공격 속도 증가와 추가 대상 공격 |
| W | 7발의 다발 화살 |
| E | 관통 화살 |
| R | 충전형 화살비 궁극기 |
| D / F | 선택한 특수능력 |
| 왼쪽 Shift | 커서 방향 무적 회피, 2회 순차 충전 |
| Escape | 조준 취소 또는 일시정지/재개 |

대상 지정 스킬은 범위를 확인한 뒤 좌클릭하면 발동합니다. 슬롯별 즉시 시전을 켜면 추가 클릭을 생략합니다. 가만히 서 있거나 일반 이동 중에는 자동으로 공격하지 않습니다.

위 Q/W/E/R 설명은 궁수 기준입니다. 직업을 선택하면 HUD의 스킬과 조준 방식도 바뀝니다.

| 직업 | 기본 공격 | Q | W | E | R |
| --- | --- | --- | --- | --- | --- |
| 검사 | 근접 타격 | 다음 공격 강화 및 주변 피해 | 피해 반사 보호막 | 이동하며 회전 공격 | 지점 지정 대검 낙하, 중심 추가 피해 |
| 궁수 | 원거리 화살 | 집중 사격 | 다발 화살 | 관통 화살 | 화살비 |
| 마법사 | 가까운 적에게 연쇄 번개 | 폭발 화염구 | 주변 피해 및 이동 불가 | 지정 지점 순간이동과 주변 피해 | 피해와 스킬 회복 속도 강화 |

## 확인해 볼 내용

1. 직업과 D/F 특수능력을 선택하고 시작합니다. 검사·궁수·마법사를 각각 확인하세요.
2. 원본과 비교해 이동, 공격 이동, 회피의 조작감을 확인합니다.
3. Q/W/E로 적 3마리를 처치해 첫 증강을 선택합니다. 카드별 리롤과 직업별 스킬 효과도 확인합니다.
4. 5레벨에 등장하는 엘리트를 처치하고 특별 증강을 선택합니다.
5. 사망 결과와 재도전을 확인합니다. 캐릭터 크기, UI 가독성, 전투 느낌에 대한 의견을 알려주세요.
6. 캐릭터 주위의 여덟 방향으로 이동·공격해 앞모습, 뒷모습, 옆모습과 무기의 방향을 확인합니다.

이번 검토에서는 원본 밸런스를 유지합니다. 멀티플레이, 온라인 랭킹, 광고 SDK와 외부 배포는 포함하지 않습니다.
