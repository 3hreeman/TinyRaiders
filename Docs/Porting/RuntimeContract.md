# First playable runtime API contract

## Full roster extension

`GameSimulation(uint seed=1, string specialD="heal", string specialF="haste", string character="archer")` and `SurvivorGame.StartRun` accept the same optional fourth character argument. Original IDs are `swordsman`, `archer`, and `mage`; `RunState.Character` identifies the active kit. Existing archer calls remain valid.

The catalog is interpreted for all twelve player skills. `GameSimulation.GetSkillTargeting(int slot)` returns `Data.TargetingData` after augment patches, and `CooldownRecovery(int slot)` includes permanent haste and temporary mage overload. Source QWER targeting is read from this data; self casts activate immediately, direction/point casts obey the selected quick-cast mode.

`RunState.Buffs` holds source skill buff duration, damage/attack/movement/cooldown/incoming modifiers, extra targets, and empowered melee charges. `RunState.Chains` holds delayed unique-target mage lightning. `DamagePlayer(float amount, int sourceId=-1)` supports shield reflection to the actual attacker. `Player.SkillShield`, `SkillShieldRemaining`, and `SkillShieldReflect` are separate from D/F `Shield`/`ShieldRemaining`; presentation should display their summed absorption.

Source augmentation paths are stored in `SkillState.Patches` and applied when executing effects and building target previews. Extra skill effects remain ordered in `SkillState.AddedEffects`. The effect interpreter supports buffs, shields, teleport, area damage/root, projectiles with explosion/penetration, falling arrows, and timed/following zones. Existing snapshot fields remain compatible; zones add `FollowCaster`, `TicksLeft`, `CoreRadius`, `CoreMultiplier`, `Root`, and `SourceId`; projectiles add `Explosion`, `Root`, `Penetrations`, and `SourceId`.

Presentation discriminators: `ProjectileState.Visual == "fireball"` for mage Q; `ZoneState.Visual == "spin"` for swordsman E and `"sword"` for swordsman R; `EffectState.Kind == "lightning"` carries `End`, `Elevation`, and `FromStaff`; melee strikes use `"slash"`. Source default SD bow/staff sockets share the original .55 visual scale. Projectile `Elevation` is separate from ground collision. Motion fields preserve source-world radians and animation progress for eight-direction art selection.

Regression cases include shield reflection after its absorption pool empties but before its three-second duration expires; source sword spin's twenty quarter-second ticks; ultimate core damage excluding enemy radius; mage chain hops every .14 combat seconds with no repeat victims; fireball explosion once per collision, with a second collision only after a penetration augment; teleport applying area damage at its clamped destination; and overload affecting QWER recovery but not D/F or dodge recharge. Frozen overlays pause all delayed deliveries and buffs.
Namespace `SurvivalLegend`. All world positions are `UnityEngine.Vector2`, source coordinates x/right y/down in 1440×1440. Exact source projection: screen x=640+(x-y)*.39; screen y=260+(x+y-1440)*.155. Simulation runs fixed 1/60 seconds.

`SurvivorGame : MonoBehaviour` has public `RunState State`, `GameSimulation Simulation`, static `SurvivorGame Instance`, public `Vector2 CursorWorld`; calls presentation-independent simulation. Commands: `StartRun(uint seed=1, string specialD="heal", string specialF="haste")`, `ReturnToTitle()`, `TogglePause()`, `ChooseAugment(int index)`, `RerollAugment(int index)`, `CastSkill(int slot,Vector2 target)`, `UseSpecial(int slot,Vector2 target)`, `Dodge(Vector2 target)`, `MoveTo(Vector2)`, `AttackMove(Vector2)`, `Attack(int enemyId)`, `Stop()`. Presentation owns pointer conversion: assign CursorWorld every frame and optionally call movement commands on right/left click. Controller handles keyboard QWER/DF/Shift/A/S/Escape/Space, mouse right uses CursorWorld; A then left click attack-move. WASD movement is NOT enabled (A/S are commands).

`RunPhase { Title, Playing, Paused, LevelUp, AugmentEnter, Augment, EliteDeath, Dying, Results }`. `RunState`: Phase; Player; List<EnemyState> Enemies; List<ProjectileState> Projectiles; List<ZoneState> Zones; List<EffectState> Effects; List<AugmentChoice> AugmentChoices; List<string> History; SkillState[4] Skills; SpecialState[2] Specials; float Time, Ultimate, PhaseElapsed, DamageDealt, DamageTaken, Healing; int Level, Kills, Xp, NextXp, EliteKills; string Notice; float NoticeTime; uint Seed; bool SpecialReward; int DodgeCharges; float DodgeRecharge, DodgeRemaining; string Order; Vector2? Destination; int TargetId; int AimSlot (-1 none, 0..3 skills, 4..5 specials, 6 attack).

`PlayerState`: Vector2 Position; float Hp,MaxHp,Speed,Damage,AttackSpeed,Range,Armor,HealthRegen,Lifesteal,CritChance,CritMultiplier,Facing,Invulnerable,Shield,ShieldRemaining; bool Moving; float AttackAnimation,FocusRemaining,HasteRemaining.
`EnemyState`: int Id,Level; string Kind (`chaser`,`shooter`,`caster`,`elite`); Vector2 Position; float Hp,MaxHp,Radius,Speed,Damage,Facing,AttackTimer,Windup,Root,Flash; bool Moving; string Pattern; Vector2 Aim; float PatternAngle.
`ProjectileState`: int Id; Vector2 Position,Velocity; float Radius,Damage,Life; bool Hostile,Pierce; string Visual; HashSet<int> Hits.
`ZoneState`: int Id; Vector2 Position; float Radius,Warning,Life,Interval,Tick,Damage,Angle,Length,Width; bool Hostile; string Shape (`circle`,`rectangle`,`fan`), Visual; float Arc.
`EffectState`: Vector2 Position,End; string Kind,Text,Color; float Life,MaxLife,Radius; bool Critical.
`SkillState`: string Id,Name,Description; int Level; float Cooldown,Remaining,DamageMultiplier=1,AreaMultiplier=1; int Repeats; float Haste.
`SpecialState`: string Id,Name; float Cooldown,Remaining.
`AugmentChoice`: string Id,Title,Description,Tier,Kind,Stat; float Value; int SkillSlot; string Upgrade; bool Rerolled.

`GameSimulation`: public RunState State; ctor(uint seed=1,string specialD="heal",string specialF="haste"); same command methods (except StartRun/title); `Step(float dt)`; static `KillsForNextLevel(int)`, `MitigatedDamage(float,float)` for tests; `SpawnEnemy(string kind,Vector2 position,int level=1)` returns EnemyState; `DamageEnemy(EnemyState,float,bool charge=true)` and `DamagePlayer(float)` for meaningful fixture testing. Constructor starts Playing; SurvivorGame starts Title.

Data is bound through `SurvivalLegend.Data.SurvivalLegendCatalog`: actual gameplay consumes the typed character, skill, special, enemy, spawn, normal-augment, and special-augment registries. JSON is a reviewable source export. No reflection is used in gameplay or presentation access. Editor bootstrap creates camera + SurvivorGame + SurvivorPresentation and saves the playable scene; it does not modify unrelated scenes automatically. Presentation Update runs at execution order50 and controller at100. The controller also exposes PointerOverUi, RequestCast(int), QuickCast, and QuickCastSlots[6]. Kills is total kills; ordinary results kills = Kills-EliteKills.
