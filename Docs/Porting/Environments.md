# 필드 프리팹과 이동 판정

## 씬에서 환경 변경

`SurvivalLegendGameObjects` 씬을 열고 Play 모드를 종료한 상태에서 메뉴 `Survival Legend > Environments`의 `Apply Grassland`, `Apply Desert`, `Apply Cave`를 선택합니다. 현재 필드 인스턴스를 해당 프리팹으로 바꾸고 게임 세션·WorldPresenter 참조를 연결한 뒤 씬을 저장합니다. 기본 적용 필드는 초록색 평원입니다.

세 필드는 `Assets/SurvivalLegend/Prefabs/World/Environments/`의 `ArenaMap-grassland.prefab`, `ArenaMap-desert.prefab`, `ArenaMap-cave.prefab`입니다. 하위 장식도 개별 프리팹 인스턴스이며 Prefab Mode에서 위치, 크기, 이미지와 충돌 반경을 조정할 수 있습니다.

## 구조

- `Backdrop`: 새 바닥 이미지. 화면 상단의 직사각형 전투 영역을 채웁니다.
- `Ground`, `FloorTiles`: 추가 바닥 오브젝트를 배치할 수 있는 레이어.
- `Decorations/BlockingProps`: 나무, 바위, 선인장, 석주, 결정 등의 이동 장애물.
- `Decorations/GroundDetails`: 작은 풀, 꽃, 모래결, 버섯 등 통행 가능한 장식.
- `Bounds`, `SpawnMarkers`: 경계 및 스폰 지점 편집용 레이어. 별도 마커가 없으면 전투 시뮬레이션이 맵 가장자리에서 스폰 위치를 정합니다.

`EnvironmentDecoration`의 `Blocks Movement`와 `Radius`가 이동 판정의 기준입니다. 원형 반경은 논리 좌표 단위이며 선택하면 지면의 충돌 범위를 Gizmo로 표시합니다. Transform의 위치에서 논리 좌표를 계산합니다. 시각 크기와 충돌 반경은 별도로 편집합니다. 넓거나 불규칙한 장애물에는 여러 개의 원형 장애물을 조합할 수 있습니다.

## 이동 방식의 변경 이유

기존은 목적지 방향으로 직선 이동한 뒤 맵 경계만 제한했습니다. Collider를 프리팹에 붙이는 것만으로는 이 시뮬레이션의 위치 갱신을 막을 수 없어, 논리 좌표의 충돌·경로탐색을 추가했습니다. Rigidbody나 Unity 물리로 전투 결과를 변경하지 않습니다.

실행 시작 시 배치된 장애물을 `GameContentSnapshot`으로 복사합니다. 플레이어와 몬스터는 자신의 반경까지 고려한 경로로 장애물을 우회합니다. 정적 격자와 목적지별 공유 경로 데이터를 사용하며 표현용 프리팹과 전투 난수는 분리되어 있습니다. 회피·순간이동·끌어당김은 이동 구간을 검사해 첫 장애물 앞에서 멈춥니다. 장애물 편집 결과는 다음 게임 시작에 반영됩니다.

경로 격자는 논리 좌표 32단위이며 캐릭터 여유 반경을 4단위로 올림합니다. 아주 좁은 틈은 통행 불가로 판정될 수 있으므로 큰 몬스터가 지나갈 통로에는 충분한 여유를 둡니다. 가장자리 전체를 장애물로 막으면 안전한 스폰 위치를 찾지 못하므로 통로를 남겨야 합니다. 기본 세 맵은 중앙 시작 공간과 가장자리 진입 통로를 확보했습니다.

이동 충돌에 한정된 변경입니다. 투사체·장판의 피해 판정은 기존 규칙을 유지합니다. 얇은 지면 장식은 통행 가능하며 큰 입체 오브젝트와 구분됩니다.

## 좌표와 아트

논리 맵은 3600 × 3600으로 확장되었으며 기본 카메라 시야는 약 1440 × 2068입니다. 카메라 화면은 1280 × 720 기준 `(40,45)`부터 크기 `1200 × 675`의 직사각형으로 하단 HUD 뒤까지 이어집니다. 월드 좌표 변환의 기준 크기 `1200 × 470`은 유지하므로 배치된 오브젝트와 충돌 좌표는 바뀌지 않습니다. 클릭 역변환은 실제 카메라의 위치와 줌을 반영합니다. 깊이 정렬은 논리 좌표를 기준으로 유지하고, 투사체와 8방향 캐릭터도 같은 좌표계를 사용합니다. 확대된 맵은 바닥 청크 9개, 장애물 60개, 바닥 장식 120개로 구성됩니다. 카메라·안개·미니맵 설정은 `CameraFogMinimap.md`를 참고합니다.

바닥 PNG는 `Assets/SurvivalLegend/Resources/Art/Environments/`에 저장됩니다. 내장 imagegen으로 제작했고 프롬프트는 같은 문서 폴더의 `EnvironmentImagePrompts.md`에 기록합니다. 장식 PNG는 Unity 에디터 제작 코드에서 픽셀 도형을 조합하여 생성합니다. 생성 도구는 이미 존재하는 장식 리소스를 보존하므로 직접 수정할 수 있습니다.
