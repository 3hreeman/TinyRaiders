# 카메라 및 탐색 기능 검증

2026-09-21, Unity Editor 6000.5.4f1. 별도 PC/WebGL 빌드는 생성하지 않았습니다.

- EditMode **104/104 통과**, 실패 0, 생략 0. 카메라 경계/줌, 자유 이동과 추적, 화면 역변환, 뷰포트/가장자리 입력, 안개 상태, 확대된 맵과 저장된 미니맵 참조를 포함합니다.
- 세 맵은 3600 × 3600, 바닥 청크 9개, 장애물 60개, 장식 120개입니다. 가장 큰 몬스터가 네 가장자리에서 중앙으로 이동할 수 있음을 검사했습니다.
- 실제 Play 모드에서 자유 카메라 중 플레이어 이동이 카메라를 바꾸지 않음, FocusPlayer의 즉시 중심 이동/추적, 미니맵 PointerEventData 클릭의 카메라 이동과 캐릭터 명령 보존을 확인했습니다.
- 여러 줌 값과 범위 밖 이동 요청에도 카메라 시야 전체가 맵 내부에 유지됩니다.
- 실제 적 View를 검사해 현재 시야의 적만 활성화되고 탐색 후 시야 밖으로 벗어난 적은 숨겨짐을 확인했습니다. 새 게임의 탐색 기록 초기화도 통과했습니다.
- 1920 × 1080 Game View에서 기본 시야와 이동 후 탐색 흔적·축소 화면을 확인했습니다. `camera-fog-minimap.png`, `camera-explored-zoom.png`에 기록했습니다.
- 최종 저장 씬은 평원이며 카메라 컴포넌트 활성, 안개/미니맵 연결 정상, 누락 스크립트 0개, Play 모드 종료입니다.

원시 런타임 결과: `camera-fog-runtime-checks.txt`, `camera-fog-scene-check.txt`. 검증용 적과 이동 좌표는 임시 Play 모드 상태이며 씬/게임 데이터에 저장하지 않았습니다. 마우스/키 하드웨어 이벤트의 자동 입력 재생은 수행하지 않았으며 해당 바인딩은 코드 확인과 호출 API 검증을 병행했습니다.
