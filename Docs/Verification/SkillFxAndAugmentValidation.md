# 스킬 FX 및 증강 카드 검증

검증일: 2026-09-21. Unity Editor에서 확인했으며 별도 플레이어 빌드는 생성하지 않았습니다.

## 결과

- EditMode 테스트 67개 통과, 실패·생략 0개. 전투 회귀, 특수 스킬의 표현 이벤트, 실제 GameDatabase에 등록된 스킬의 FX 연결, 카드 Graphic의 CanvasRenderer 연결을 포함합니다.
- 레벨업 시 전체 화면 전환 패널이 비활성 상태이며 캐릭터 주변에 LEVEL UP 텍스트와 파티클이 한 번 표시됩니다. 검증 프레임에서 파티클 26개를 확인했습니다.
- 검사·궁수·마법사의 네 가지 스킬을 각각 발동해 화면을 확인했습니다. 28개 FX 프로필이 연결되어 있습니다.
- 일시정지 후 파티클 시간이 유지됩니다. 사용 중인 파티클 셰이더는 현재 에디터의 렌더링 환경에서 지원됩니다.
- 투사체 TrailRenderer에 실제 궤적 12점을 확인했습니다. 재시작 후 기존 파티클과 트레일은 비워집니다.
- 이벤트 220개를 연속 전달한 검증에서 활성 FX는 128개 상한을 지켰습니다. 정리 후 비활성 풀은 89개로 상한 이내였습니다.
- 증강 카드는 중앙에서 순차적으로 펼쳐집니다. 등장 중에는 선택을 막으며 완료 후 선택 가능합니다. 마우스 오버 시 배율 1.045를 확인했습니다.
- 다시 뽑기 후 해당 카드만 재등장하고 다시 뽑기 제한이 유지됩니다. 카드 선택 후 증강 이력에 반영되고 선택 화면이 닫히며 Playing 상태로 복귀합니다.
- 최종 씬 `SurvivalLegendGameObjects`: 저장되지 않은 변경 없음, 누락된 컴포넌트 0개, GameDatabase 유효, HUD 슬롯 6개. Play 모드 종료 및 Full HD 복원.

## 화면 기록

- `fx-levelup.png`: 캐릭터 주변 레벨업 안내.
- `fx-swordsman.png`, `fx-archer.png`, `fx-mage.png`: 직업별 스킬 연출.
- `augment-reveal.png`: 중앙에서 펼쳐지는 등장 연출.
- `augment-tiers.png`: 실버·골드·프리즘 카드 비교.
- `augment-hover.png`: 마우스 오버 확대.

화면 비교용 등급과 적 체력은 Play 모드의 임시 상태로 설정했으며 게임 데이터 에셋에 저장하지 않았습니다. 카드 선택 규칙과 전투 밸런스는 유지했습니다. PC/WebGL 배포 환경의 성능·렌더링 검증은 이번 에디터 검증에 포함하지 않았습니다.
