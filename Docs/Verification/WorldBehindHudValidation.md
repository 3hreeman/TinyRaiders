# HUD 뒤 월드 표시 검증

- 카메라 표시 영역: 1280 × 720 기준 (40,45), 1200 × 675. 하단 HUD 뒤까지 렌더링.
- 기본 Orthographic Size 3.375, 최소 1.6875로 기존 캐릭터 화면 크기를 유지.
- 월드 투영 좌표와 프리팹 배치, HUD 오브젝트는 유지.
- EditMode: 104/104 통과. 줌/팬 맵 경계, 화면 좌표 역변환, 변경된 하단 가장자리와 해상도별 뷰포트 포함.
- 1920 × 1080 Play Mode에서 자유 카메라를 이동해 HUD 뒤 지형 및 캐릭터 표시와 미니맵 카메라 영역 확인.
- 확인 이미지: world-behind-hud.png. 전장의 안개는 정상 적용하며 스크린샷은 자유 카메라를 위쪽으로 이동한 상태.
- 씬에 카메라 설정 저장. 검증 후 Play Mode 종료. 별도 빌드 없음.
