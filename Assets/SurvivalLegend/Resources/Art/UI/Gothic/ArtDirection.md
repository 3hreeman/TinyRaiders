# Gothic HUD image assets

Generated with the built-in imagegen tool, using the two supplied HUD/gameplay screenshots as visual references only. Both final PNGs are 1254×1254 RGBA. The four corner pixels have alpha 0 in each file; the orb center has alpha 253. Import as Unity UI sprites with alpha transparency enabled, no mipmaps. Keep the sculpture and orb on separate Image objects; mirror the guardian horizontally for the right orb. The neutral orb is intended to receive red or gold Unity Image tint and a separate vertical fill mask.
