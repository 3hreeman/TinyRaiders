# Editable environment art

`Editor/World/EnvironmentArtBuilder.EnsureAssets()` creates three independent `ArenaMapView` prefabs in `Prefabs/World/Environments`: `ArenaMap-grassland`, `ArenaMap-desert`, and `ArenaMap-cave`. `LoadMapPrefab(id)` returns one by ID. Each prefab keeps the expected Backdrop, Ground, FloorTiles, Decorations, Bounds, and SpawnMarkers layers. The full source floor PNG is imported as a single sprite and scaled across the 1200 × 470 field rectangle. Backdrop sorting is −10000, nonblocking ground details −5000, and raised props use the same foot-depth order as actors.

The current logical map is 3600 × 3600. The editor migration retains every original prefab instance and its artist overrides, moving the original district to the middle of the expanded arena. It adds four mirrored outer districts from the reusable prop/detail prefabs: 60 blocking props and 120 small ground details per biome. `Layout3600-v1` marks the one-time move so later builder runs preserve hand adjustments. Nine floor SpriteRenderers cover the map exactly: full 1440-unit chunks, plus derived half-size edge sprites. Alternate rows and columns mirror the source texture at seams; the supplied full-size PNGs remain untouched.

`BlockingProps` contains twelve editable obstacle prefab instances per biome. The centre spawn area and perimeter lanes remain open. `GroundDetails` contains twenty-four small, nonblocking sprites. Reusable prop prefabs and their native pixel PNGs are saved beside the maps; trees, boulders, stumps, cacti, sandstone pillars, dark basalt, and crystal clusters use layered shaded silhouettes and contact shadows. Floor sprites come from the supplied `grassland-floor.png`, `desert-floor.png`, and `cave-floor.png` and are never regenerated by this builder.

Move a prop's root transform to edit its logical location. `EnvironmentDecoration.LogicalPosition` converts that foot location back through `WorldProjection`. Its `Radius` is in logical world units and does not change when an artist scales the sprite. `BlocksMovement` controls whether the prop contributes to the gameplay obstacle snapshot. Selecting a blocking prop shows its actual projected circular collision gizmo. Prefab instances retain editable position, visual scale, and radius overrides. The default reusable prop prefabs also carry collision radii when placed separately.

The generated props use 128 × 128 point-filtered RGBA sprites with transparent backgrounds and a bottom foot pivot. The sprite layers are editable in each prop prefab. Generated PNGs are written only if absent, preserving subsequent paintovers. The map builder also preserves an existing prefab's authored hierarchy when run again; to restore its initial scatter, remove the prefab and rerun the builder.

`Editor/UI/MinimapAuthoring.Apply(ui, game, map, fog, cameraController)` adds a compact interactive minimap to the bottom-right HUD. It samples the same mirrored terrain art and layers obstacle/enemy dots below the fog texture, with the camera viewport and player dot above it. The minimap uses the complete logical extent; clicking it calls `PanToLogical`. The camera's Space control remains the return-to-player action.
